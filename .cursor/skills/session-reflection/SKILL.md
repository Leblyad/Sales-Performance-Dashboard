# Session reflection

## When to use

The session is over, or the user asks to record how the work went. Not after every prompt.

## Steps

1. Append 10–30 substantive lines to the root `AI_NOTES.md`.
2. Cover: models and tools; what was delegated; what was designed by hand; where AI saved time; where it was wrong; what was rejected or rewritten; how the code was checked.
3. Do not copy the verbatim requests. Those stay in `AI_PROMPTS.md`. Do not copy this text into the vault.

## Notes

Skip a bullet that did not happen. Do not pad the note with generalities.
