# {{title}}

> Один endpoint или один согласованный набор, который кормит блок экрана.

## Context

Какой блок UI питает: KPI, рейтинг, динамика, категории, последние продажи. См. [[Разбор задания/04 Dashboard/Экран]].

## Details

- Метод и путь.
- Параметры периода и что они значат (включительность границ — как в [[Разбор задания/03 Домен/Открытые решения]]).
- Тело ответа: поля и в каких единицах деньги и доли.
- Ошибки валидации.
- Какой SQL / запрос EF это закрывает и почему нет N+1.
- Что клиент не должен догружать отдельно.
