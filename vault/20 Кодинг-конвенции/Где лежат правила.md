# Где лежат правила кода

> Правила агентов — в `AGENTS.md` своей зоны. Домен задания — в этом vault. Одно и то же в двух местах не копировать.

## Context

Три чата Cursor. Промпт-агент — корень репозитория. Backend и frontend открываются своими каталогами.

`backend/SalesDashboard.Api` — один проект на .NET 10. Мок `Item` в коде больше не лежит. Ошибки: `Exceptions/AppException` и `AppExceptionHandler`. Логи: NLog, `nlog.config`. Приложения `frontend/` ещё нет.

## Details

- Промпт-агент: корневой `AGENTS.md`. Журнал — `AI_PROMPTS.md` и `AI_NOTES.md` в корне, не в vault.
- Backend: `backend/AGENTS.md`. Кодстайл: `backend/AGENTS/coding-rules.md`.
- Frontend: `frontend/AGENTS.md`. Стек UI: `frontend/react-client.md`.
- Заметка vault при смене домена, API или архитектуры — скилл `.cursor/skills/update-vault-note`. Куда класть факт — [[01 Онбординг/Как вести заметки]].
- Outbox, HttpClient, репозитории и отдельные сборки не возвращать.
- Бизнес-правила dashboard — [[Разбор задания/03 Домен/Показатели и статусы]] и [[Разбор задания/03 Домен/Открытые решения]].

## Decisions

Один проект `SalesDashboard.Api`. Мок `Item` в коде больше не лежит. Стек клиента зафиксирован в [[02 Архитектура/Стек клиента]].
