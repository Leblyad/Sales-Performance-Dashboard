# Локальный запуск

> Runbook на одну команду из корня: `docker compose up --build`.

## Context

Проверяющий не ставит SDK, не открывает PgAdmin и не запускает seed отдельно. Критерий приёмки — [[Разбор задания/01 Онбординг/Запуск и сдача]]. Seed отдельным сервисом в этот compose не входит. Сервис `frontend` входит.

## Details

1. Из корня репозитория: `docker compose up --build`.
2. Адрес API: http://localhost:8080/health.
3. Адрес экрана: http://localhost:5173. Это сервис `frontend`: nginx внутри слушает 80.
4. Миграции, включая `Seed`, проходят при старте сервиса `api`, до приёма запросов. `Seed` выполняет `backend/seed/seed.sql`. Отдельная команда `dotnet ef` для этого не нужна.
5. Сброс: `docker compose down -v`, затем снова `docker compose up --build`. Seed загрузится миграцией заново.
6. Seed отдельным сервисом в этот compose не входит.

Команда `dotnet run` не считается сдачей. Отдельный запуск `frontend/Dockerfile` без compose тоже не считается сдачей.

## Decisions

Приёмочная команда зафиксирована ТЗ: `docker compose up --build`.
