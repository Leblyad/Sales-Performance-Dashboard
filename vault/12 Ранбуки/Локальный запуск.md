# Локальный запуск

> Runbook на одну команду из корня: `docker compose up --build`.

## Context

Проверяющий не ставит SDK, не открывает PgAdmin и не запускает seed отдельно. Критерий приёмки — [[Разбор задания/01 Онбординг/Запуск и сдача]]. Seed и контейнер frontend в этот compose не входят.

## Details

1. Из корня репозитория: `docker compose up --build`.
2. Адрес API: http://localhost:8080/health.
3. Миграция `InitialSchema` проходит при старте сервиса `api`, до приёма запросов. Отдельная команда `dotnet ef` для этого не нужна.
4. Сброс: `docker compose down -v`.
5. Seed и контейнер frontend в этот compose не входят. После сброса остаётся пустая схема, без данных seed.

Команда `dotnet run` не считается сдачей. Образ заглушки клиента (`frontend/Dockerfile`, снаружи порт 5173) тоже не заменяет compose.

## Decisions

Приёмочная команда зафиксирована ТЗ: `docker compose up --build`.
