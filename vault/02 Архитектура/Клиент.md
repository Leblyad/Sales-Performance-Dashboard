# Клиент

> Стек выбран. В `frontend/` лежит каркас Vite и заглушки блоков, не экран.

## Context

Требования к странице — [[Разбор задания/04 Dashboard/Экран]] и [[Разбор задания/04 Dashboard/Состояния и граничные случаи]]. Считать KPI в браузере нельзя, см. [[Разбор задания/05 API/Требования]].

Правила и список библиотек — `frontend/react-client.md`. Почему так — [[02 Архитектура/Стек клиента]].

## Details

Уже решено:

- React 19, TypeScript, Vite, TanStack Router, TanStack Query, Zustand, Zod, React Hook Form, Tailwind, shadcn/ui, Vitest, Testing Library, Playwright, MSW, ESLint, Prettier;
- одна страница в браузере около 1440×900, без mobile и без входа.

`npm run dev` в `frontend/` открывает заглушку на Vite. Тот же каркас можно собрать образом `frontend/Dockerfile`: nginx внутри слушает 80, локальная проверка открывает порт 5173. Это не URL готового dashboard и не команда сдачи.

Пока не заполнено:

- URL, который увидит проверяющий;
- библиотека графиков и таблица рейтинга;
- как период с экрана совпадает с контрактом в [[Разбор задания/05 API/Требования]].

## Decisions

Библиотеку графиков не выбирать, пока она не записана в `frontend/react-client.md` и в эту заметку.
