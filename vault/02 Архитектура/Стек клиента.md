# Стек клиента

> Почему клиент собирается по `frontend/react-client.md`. Чтобы не выбирать UI-кит заново в каждом чате.

## Context

ТЗ не назначает UI-кит и графики. Без зафиксированного списка агент либо берёт примеры из PDF, либо откладывает выбор. Экран ещё не создан.

## Details

- Варианты: оставить библиотеки незакрытыми до первого экрана или принять список, который уже лежал в правилах React-клиента.
- Выбрано: React 19, TypeScript, Vite, TanStack Router, TanStack Query, Zustand, Zod, React Hook Form, Tailwind, shadcn/ui, Vitest, Testing Library, Playwright, MSW, ESLint, Prettier. Источник — `frontend/react-client.md`.
- Цена: стек шире одной страницы. Менять его можно только вместе с этой заметкой.
- Библиотека графиков не выбрана: в файле правил её нет.
- Кода клиента ещё нет. Приложение не создавалось в этом решении.

## Decisions

Примеры пакетов из ТЗ не становятся вторым стеком. Next.js и вход в приложение не входят в выбор.
