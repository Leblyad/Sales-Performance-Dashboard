# DTO dashboard

> DTO повторяют результаты и параметры запросов dashboard. Страница — Items, Skip и Take. У рейтинга и категорий к странице добавлен режим сортировки.

## Context

Запросы dashboard собирают модели чтения рядом с EF. Отдавать эти модели вызывающему коду значило бы связать форму ответа с типом запроса.

## Details

- Варианты: отдавать модели из `Data`, либо отдельные DTO с теми же полями.
- Выбрано: DTO в `backend/SalesDashboard.Api/Dto`. Поля результата совпадают с полями результата соответствующего запроса. У запроса с параметрами своя модель параметров. У пяти продуктов модели параметров нет.
- `PageDto` — Items, Skip, Take. Его возвращает чтение последних продаж.
- `SortedPageDto` — то же плюс Sort. Sort — режим, уже выбранный в запросе. Его возвращают рейтинг менеджеров и категории. Общего количества строк нет.
- KPI и динамика возвращают свои DTO без обёртки. Динамика — список. Пять продуктов — список своих DTO.
- Сопоставление результатов — `backend/SalesDashboard.Api/Mapping/DashboardRegister.cs`, через уже подключённый Mapster. Второго `Scan` нет.
- Endpoint не заводится.

## Decisions

Total, пагинация KPI, динамики и пяти продуктов, проверка знака skip и take и новые режимы сортировки не входят. Пункты 4–10 в [[Разбор задания/03 Домен/Открытые решения]] остаются открытыми.
