# Контракты API

> Указатель endpoint'ов, которые уже есть в коде. Ограничения ТЗ — [[Разбор задания/05 API/Требования]], их отсюда не копировать.

## Context

Аналитические пути dashboard записаны ниже. Frontend не должен получать сырые тысячи продаж, чтобы посчитать dashboard.

## Details

| Блок экрана | Метод и путь | Заметка |
|-------------|--------------|---------|
| KPI | `GET /api/dashboard/kpi` | [[05 API/Dashboard]] |
| Рейтинг менеджеров | `GET /api/dashboard/ranking` | [[05 API/Dashboard]] |
| Динамика | `GET /api/dashboard/dynamics` | [[05 API/Dashboard]] |
| Категории | `GET /api/dashboard/categories` | [[05 API/Dashboard]] |
| Продукты | `GET /api/dashboard/products` | [[05 API/Dashboard]] |
| Последние продажи | `GET /api/dashboard/sales` | [[05 API/Dashboard]] |

Новый контракт — файл в этой папке по [[Шаблоны/API-контракт]] и строка в таблице. В той же задаче, что и код endpoint'а.

## Decisions

Шесть путей dashboard записаны в таблице. Другие URL заранее не заполнены.
