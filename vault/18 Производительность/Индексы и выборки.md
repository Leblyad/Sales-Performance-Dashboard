# Индексы и выборки

> Сюда попадает то, что нужно уметь объяснить на проверке: почему агрегаты считаются так и какие индексы под них.

## Context

ТЗ смотрит на PostgreSQL отдельно от ORM: индексы по месту, aggregate-запросы, понятный SQL, отсутствие очевидных N+1. Raw SQL допустим для отдельной аналитической выборки. См. [[Разбор задания/02 Архитектура/Ограничения]] и [[Разбор задания/05 API/Требования]].

Объём seed — 2 000–5 000 продаж, см. [[Разбор задания/06 Данные/Seed и PostgreSQL]].

## Details

Когда появится аналитический запрос, дописать строку:

| Запрос | Где в коде | Почему ORM или raw SQL | Индекс |
|--------|------------|------------------------|--------|
| kpi_cards | `backend/SalesDashboard.Api/Data/Queries/KpiCardsQuery.cs` | SQL в миграции, вызов через EF Core | нет |
| manager_rankings | `backend/SalesDashboard.Api/Data/Queries/ManagerRankingQuery.cs` | raw SQL view через EF Core, у метода есть skip и take | нет |
| manager_dynamics | `backend/SalesDashboard.Api/Data/Queries/ManagerDynamicsQuery.cs` | SQL в миграции через EF Core | нет |
| категории | `backend/SalesDashboard.Api/Data/Queries/CategoryStatQuery.cs` | LINQ-запрос EF Core от Category, у метода есть skip и take | нет |
| пять продуктов | `backend/SalesDashboard.Api/Data/Queries/TopProductsQuery.cs` | LINQ-запрос EF Core от Product | нет |
| последние продажи | `backend/SalesDashboard.Api/Data/Queries/RecentSalesQuery.cs` | LINQ-запрос EF Core от Sale, у метода есть skip и take | нет |

Индексы «на всякий случай» не заводить.

## Decisions

Процедура `kpi_cards` читается через EF Core. Индекса под неё нет. Представление `manager_rankings` читается через EF Core, у метода есть skip и take. Индекса под него нет. Процедура `manager_dynamics` читается через EF Core. Индекса под неё нет. Категории читаются одним LINQ-запросом EF Core от Category, у метода есть skip и take. Индекса под него нет. Пять продуктов читаются одним LINQ-запросом EF Core от Product. Индекса под него нет. Последние продажи читаются одним LINQ-запросом EF Core от Sale, у метода есть skip и take. Индекса под него нет.
