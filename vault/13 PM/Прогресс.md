# Прогресс

> Этапы из ТЗ. История коммитов должна быть про них же, не одним финальным коммитом и не россыпью без названий.

## Context

Ориентир — 8 часов. Незакрытый этап в рабочей системе нормален, если он честно стоит в этой таблице и в [[21 Техдолг/Не успели]]. Критерий запуска — [[Разбор задания/01 Онбординг/Запуск и сдача]].

Обновление строки — заметка по [[Шаблоны/Запись прогресса]] не обязательна для мелкой правки: достаточно поменять статус здесь в той же задаче, что и код.

## Details

Статусы сверены с репозиторием на 2026-09-30.

| Этап | Статус | Что уже есть |
|------|--------|----------------|
| initial project structure | частично | `backend/SalesDashboard.Api` — хост и свой Dockerfile. `frontend/` — каркас Vite, Dockerfile отдаёт заглушку через nginx. Корневой `docker-compose.yml`: `postgres`, `api` и `frontend` (снаружи 5173). Vault с разбором есть |
| add sales domain and seed | частично | Классы домена в `backend/SalesDashboard.Api/Domain/`. DbSet и конфигурации в `backend/SalesDashboard.Api/Data/`. Миграции `InitialSchema` и `DropItems`. Файлы сида в `backend/seed/`. Миграция `Seed` выполняет `seed.sql` при `Database.Migrate()`. |
| implement analytics API | частично | Шесть GET в `backend/SalesDashboard.Api/Controllers/DashboardController.cs`. Seed нет. Пункт 5 не закрыт. См. [[05 API/Контракты]] |
| build dashboard UI | частично | Каркас `/` в `frontend/src`: сине-белый layout, меню переключает одну вкладку через search-параметр `section`: KPI, рейтинг, категории. Вкладка KPI: селектор периода и шесть карточек, лучший менеджер из рейтинга с Mode 0. Вкладка рейтинга — таблица на высоту секции, страницы в футере; строка открывает график менеджера справа. Вкладка категорий — таблица продаж и прибыли за свой период; строка раскрывает пять продуктов, «Подробнее» открывает продажи этой категории. Отдельных вкладок динамики, продуктов и последних продаж нет |
| add charts and animations | частично | На рейтинге линия Recharts: Revenue, Gross Profit или количество продаж за свой период. Ось чисел слева, даты снизу, значение точки при наведении. Скрытие графика возвращает таблице всю ширину |
| add tests | не начато | См. [[09 Тестирование/Что покрыто]] |

Порядок в ТЗ такой, но seed и домен не блокируют черновик UI, если API ещё пустой и это видно в таблице. Не отмечать этап готовым, пока проверка из [[12 Ранбуки/Локальный запуск]] или из тестов не совпадает со статусом.

## Decisions

«Частично» у каркаса не означает, что шаблон уже переименован под продажи. Это ещё не сделано.
